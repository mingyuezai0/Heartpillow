# 心枕 · Heartpillow

> Heartpillow（心枕）—— 放在枕边的 AI 伙伴。人设、记忆、对话，都在你自己手里。

当前版本 **v1.0.3**。

一个**单文件**应用：`心枕.html` 双击就能用，不装任何东西。数据默认只存在你自己这台机器的浏览器里。
想让它在你关掉页面之后继续陪着（QQ 自动回消息、定时计划到点主动找你、B 站代刷），把同一份 HTML 放到服务器上即可 ——
**不需要桌面版**。

---

## 它能做什么

| 模块 | 说明 |
| --- | --- |
| **对话** | 流式回复、逐条送达、图片/文件、表情包、来源标记（心枕 / QQ / B 站） |
| **人设** | 立绘、形象、人设正文、话语规范、性格滑杆、称呼；内置「大肥鱼」基础模板，也可套用其它模板（只带人设，不带记忆） |
| **记忆** | 关键记忆 / 轻度记忆（7 天自动合并）/ 关键词，全部由她自己记；内容相近的会自动合并，不会越记越乱 |
| **计划** | 每条计划带准确到点时间，界面显示倒计时；到点她用自己口吻主动发消息（页面关着由服务器发） |
| **日记** | 每天过 0 点后自己写一篇当天日记，语气像真人；也可随时让她补写 |
| **梗知识** | 聊到新梗 / 黑话 / 你们的暗号，她主动记下来；另有定期补记 |
| **表情包** | 主人同一张表情发满 3 次自动收录，她会在合适情绪下自己发 |
| **名单** | B 站按 UID、QQ 按 QQ 号；主人 / 白名单 / 普通 / 黑名单，各平台独立 |
| **外接 · QQ** | NapCat（OneBot 11）收消息，页面关着也由服务器代回；掉线自救 |
| **外接 · B 站** | 页面内扫码登录，服务器代发请求（浏览器发不了 B 站请求）；刷视频、日报、评论、私聊 |
| **日历时钟** | 侧栏秒级时钟 + 月历；提示词里带【现在】和这一周的日期表，久别重逢也算得清过了多久 |
| **数据** | 导出（当前 AI / 全部数据 × JSON / Markdown）、导入（共存或覆盖）、删除当前 AI 数据（5 秒倒计时） |
| **文档** | 应用内「文档」页：仿 DeepSeek 文档排版，含 QQ / B 站完整部署流程与各功能教程 |

隐私红线：只有**主人 / 白名单**能拿到人设与记忆，其它人只得到通用设定；发出前会过滤路径、密钥、邮箱。

## 两种用法

### 1. 只在电脑上用（最简单）

双击 `心枕.html` → 设置里填模型接口（地址 / 密钥 / 模型名）→ 开始聊。
数据在浏览器里（IndexedDB），换电脑前用「设置 → 数据 → 导出」。

### 2. 放到服务器上（QQ 自动回、B 站代刷、定时计划）

```bash
sudo bash deploy/install.sh /path/to/心枕.html    # 装网页 + 常驻客户端 + 图片代取 + nginx
sudo bash deploy/scripts/xinzhen-napcat-run.sh    # 起 NapCat（先改账号/密码）
```

浏览器打开 `http://<IP>:7863/`，设置里填模型接口，外接里连 QQ、扫码登录 B 站。
细节、自检命令和排错表见 [`deploy/README.md`](deploy/README.md)。

```
浏览器 ──> nginx :7863 ──┬─ /            心枕.html
                         ├─ /v1/         模型网关（可选）
                         ├─ /qq/api|ws  NapCat（Docker）
                         ├─ /qq/bridge/ 常驻客户端：收消息、代回、定时计划
                         ├─ /bili/      常驻客户端：B 站代跑
                         └─ /qq/img/    图片代取
```

## 仓库结构

```
心枕.html            ← 构建产物（单文件应用，直接能用）
src/
  00-shell.html      ← 骨架
  01-style.css       ← 样式（含文档页、日历、日记等）
  02-body.html       ← 界面结构
  03-app.js          ← 全部逻辑
tools/
  build.py           ← 打包成单文件（含字体子集化）
  bump.py            ← 版本号 +0.0.1 并写更新日志
  check.py           ← 无头浏览器冒烟测试（100+ 项断言）
  linktest.py        ← 外接相关回归
  shot.py            ← 截图工具
  bridge_agent.py    ← 常驻客户端的源码（部署时作为 bridge.py）
  make_icons.py / scale_fonts.py / qqguard.sh
  fontwork/          ← 字体源包（构建用；子集缓存不入库，首次构建自动重建）
deploy/              ← 服务端一键部署（见 deploy/README.md）
docs/                ← 一些会话记录
```

## 开发

```bash
python tools/build.py                # src/* → 心枕.html
python tools/bump.py "这次改了什么"   # 版本 +0.0.1，写进应用内更新日志
python tools/check.py                # 冒烟测试（无头 Edge）
python tools/linktest.py             # 外接回归
```

约定：**一批更新只 +0.0.1 一次**；每次改动都要构建、跑测试、部署后才算完成。

## 说明

- 内置的「大肥鱼」是作者自己在用的人设，作为基础模板提供，只含人设本身；
- 备份文件**不含**模型接口密钥、NapCat token、B 站登录 cookie；
- 需要自备模型接口（任何 OpenAI 兼容网关都可以，Anthropic 协议也支持）。
